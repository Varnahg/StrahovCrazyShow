## Actual implementation and evidence

WebGPU canonical notifications now borrow base Effects per submesh/pass. Each generator has independently owned derived entries per canonical source pass. A main notification neither invalidates nor rebinds the shadow entry; a changed shadow notification retires only that source pass. Same-base different-pass entries can share the actual engine Effect with two acquires, while noncanonical getEffect aliases own only draw contexts. Pending/disposed notified Effects remain authoritative; installed old-ready wrappers are never promoted. Existing shader injection and exact token/ABI recipe remain unchanged. GL retains the original single-map behavior.

Entries explicitly record origPass/originalEffect. Cleanup removes map ownership before resource disposal, releases each acquired entry once (not once per shared Effect object), nulls alias Effects before context disposal and keeps the first thrown cleanup value even when falsy. Reentrant original create callbacks cannot install retired ownership. Mesh/wrapper/pass cleanup is covered. Existing engine release Observable is subscribed/unsubscribed; no Engine patch or global observer interception is introduced. Memory can legitimately retain two live independent pass entries where the old global map retained only the last; this is live ownership, not shader history. Pass/mesh/wrapper retirement bounds lifetime. Appearance/shader/wind/color-write/quality/timeouts/camera/physics/input are unchanged source inputs and still require real WebGPU visual acceptance.

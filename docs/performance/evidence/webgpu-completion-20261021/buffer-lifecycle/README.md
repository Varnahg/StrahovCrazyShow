## Chosen scope before code

Explicit `--buffer-lifecycle` is defaultoff and part of canonical build/load/browser identity. Native Game-scene Mesh instance-update hooks establish current/previous matrix role by actual batch.parent Buffer fields before/after the original call. Own buffer-manager create/release/deferred-destroy taps and original targeted GPUBuffer.destroy calls distinguish allocation, release/refcount and actual destroy. No new GPU/readiness/render/await/fence calls. Device/scene/generation guards, original receiver/arguments/return/throw/Promise and foreign-method restore are preserved. Mesh registration uses existing native scene addition notification, not a per-frame whole-scene scan.

Only known native matrix role establishes an owner. Generic2048 vertex/storage candidates are recorded as unknown-scene/unknown-owner; thin, geometry and other buffers do not become matrix owners from the signature. Context/fastBundle identity before/after is directly observed, while encoded setVertexBuffer/setBindGroup membership remains unobserved/inferred. This helper does not install encoder graph infrastructure, change cache policy or prolong a resource lifetime.

Recent event/resource/owner windows are bounded and every eviction/overflow is exported. Target lookup on original fatal text reports exact numeric DataBuffer identity and retained owner proof or explicit not-retained/untracked. No lossless whole-session claim. Fatal/owner disposal captures before original cleanup through instance Game method taps; original health/error listeners are neither replaced nor reordered. Raw transport has a distinct receipt kind and immutable original-attempt semantics. Further root measurement and a product fix require actual owner evidence.

## Implementation and verification limits

The shared data-slot helpers and one installer/restore transaction serve every hook. IDs/rows are scalar, resource/mesh/hook objects are weak, unchanged matrix calls emit no new history rows, and native scene-add notifications avoid repeated whole-scene discovery. Original regular matrix algorithms, manager refcount/deferred destroy and NCM fastBundle replay run in CPU fixtures with fake terminal device/queue IO; this is neither a GPU reproduction nor performance evidence. Actual DataBuffer raw storage is the pinned own `_buffer`; its public `buffer` is a setter and is not read.

**Limity:** `profileEnvironment=1` také aktivoval existující podrobné WebGPU hooks/inventory. Tato čísla nelze přímo srovnávat s předchozím ručním testem bez diagnostiky; nejde o A/B, důkaz FPS zlepšení ani přejímku. Environment profil vybírá pouze celé intervaly ≥25 ms s minimální sekundovou kadencí. Neprokazuje, že jiné fáze nemají kratší špičky, a neodděluje GC/scheduling od CPU práce. Neproveden test tří relací ani worker kandidáta.

Další rozhodnutí: nejprve skutečný CPU reproduktor opakovaných dirty setter průchodů při vzniku `CharacterMaterials` nového NPC. Je to doložený kódový mechanismus, jeho podíl na uvedených transit špičkách ale zatím není známý.

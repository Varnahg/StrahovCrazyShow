# Native opaque ordering transfer

The accepted isolated QA source has 10 actual Babylon regressions and root GPU A1/B1/A2 evidence. Preserve that algorithm. Near-to-far reduces overdraw but costs distance work and can interleave material binds. Material-first removes distance sorting and groups declared pass materials; it may increase overdraw or change equal-depth order. A coarse depth bucket introduces an unmeasured threshold and is not transferred. Root accepted the measured material-first candidate for full native/combined validation, not the whole migration or a general 60 FPS claim.

The native change selects material-first only from the actual engine.isWebGPU property in ArtLighting initialization. WebGL retains the original near-to-far factory; alpha/transparent/shadow queues, shaders, quality, and vendor code remain unchanged. Effective material IDs are read without SubMesh.getMaterial/getSubMaterial side effects; no cache, observers, readiness or world mutation is added. The old comparator body and all 4 original + 6 QA tests are preserved. The additional regression runs the actual applyArtLighting initializer and actual NullEngine opaque dispatch for both backend flags. Its flag seam is not WebGPU shader/pixel/performance evidence.

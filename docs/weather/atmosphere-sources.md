# Atmosphere and stellar sky provenance

Implementation/retrieval date: **2026-10-12**. Coordinates remain the shared Strahov location, 50.08065° N, 14.39175° E; world +X is east and +Z is south. No Hogwarts Legacy artwork, texture or other game asset is incorporated. The reference informs only the authored warm/cool atmosphere and soft cloud illumination.

## Catalog and astronomy

- **Measured catalog data:** David Nash / Astronomy Nexus, [HYG v4.1](https://github.com/astronexus/HYG-Database/blob/main/hyg/CURRENT/hygdata_v41.csv), [field documentation](https://github.com/astronexus/HYG-Database/blob/main/hyg/README.md). The bundled `client/data/bright-stars.json` is a derivative selection of **925 non-solar stars with apparent visual magnitude ≤ 4.5**, preserving HYG ID, proper name, J2000 right ascension (hours), declination (degrees), visual magnitude and B−V. A missing B−V becomes 0.65; this is an explicit fallback, not a measurement. Original complete CSV SHA-256: `d9f69fd86bbf90a4e4d52b4c5c53eacfa6dfc0bfdef85bfd94f095e0bebe4ebd`; Git blob `ba2dec4eb0f6768914c7fc1051258100214ddf84`.
- **Data license:** HYG v4.1 and this filtered catalog / generated star-map derivative are [Creative Commons Attribution–ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/). Credit: David Nash / Astronomy Nexus. Changes: magnitude selection, field selection, missing-colour fallback, Gaussian display rendering. Original project implementation code is separate from the catalog data.
- **Astronomical calculation:** [US Naval Observatory, approximate sidereal time](https://aa.usno.navy.mil/faq/GAST), and [equatorial to horizontal coordinates](https://aa.usno.navy.mil/faq/alt_az). Sidereal rotation receives actual UTC epoch milliseconds, never Prague civil-time offsets. UTC approximates UT1; the difference is bounded by leap-second practice, rather than tracked from Earth-orientation bulletins.
- **Epoch correction:** the IAU 1976 J2000 precession polynomials documented in [IERS Technical Note 32, chapter 5](https://iers-conventions.obspm.fr/archive/2003/tn32.pdf) are independently evaluated and inverted to sample the J2000 catalog. The numerical reference in tests is the first column of the [ERFA `eraPmat76` reference test](https://github.com/liberfa/erfa/blob/master/src/t_erfa_c.c), MJD 50123.9999. This avoids silently rotating a J2000 catalog as if it were the equinox of 2026.
- **Limits:** this is a naked-eye visualization. It omits nutation, aberration, stellar proper motion and stellar atmospheric refraction. Catalogue magnitude variability is not animated. It is unsuitable for telescope pointing. There is no invented constellation layout or decorative Milky Way over Prague.

## Atmosphere and clouds

[Physically Based Rendering, fourth edition, phase functions](https://www.pbr-book.org/4ed/Volume_Scattering/Phase_Functions) provides the physical basis for directional scattering and the Henyey–Greenstein forward lobe. The shader uses a bounded Rayleigh angular response and forward scattering as **physical inspiration**, with an authored palette. It does not solve spectral atmospheric transport, calibrated luminance or volumetric multiple scattering.

The blue zenith, warm solar horizon, anti-solar twilight belt, silver cloud fringes and moonlit cloud edges are artistic approximations. The low urban light dome is explicitly **unmeasured Prague skyglow**. Stellar PSF size, display brightness, colour interpolation, near-horizon extinction and suppression by moonlight are display choices. The refined Gaussian core has a 0.41-texel base width; its bounded photographic response preserves integrated energy across subpixel placement, with 1.6× the initial display energy. This remains an artistic exposure. A source-backed star position is not a claim of its visibility under measured local light pollution.

Cloud coverage and low/mid/high layer amounts are provided by the existing weather pipeline, retaining its station/model/staleness labels. The continuous cloud texture is a deterministic simulation, **not a satellite image or the observed current cloud outline**. Nominal layer heights (1.4 / 3.51 / 8.512 km), texture scales (4 / 9.5 / 38 km) and cirrus stretching are game estimates. Low clouds blend rounded periodic cellular lobes with five-octave FBM. Each generated channel is calibrated with its empirical cumulative distribution so requested coverage corresponds to covered texture area. This does not guarantee that an arbitrary camera crop has the same fraction. Narrow smooth silhouettes and one sun- or moon-directed height sample give more readable cloud contours and shaded interiors. The shader's three cloud layers share their exact opacity function with sun and moon disc shaders so an opaque cloud cannot leave an unobscured celestial disc. Stars are composited behind the same layers.

Wind vectors are travelled metres per second in world axes. Meteorological source bearings are FROM bearings and are reversed before advection. Model wind aloft is used per layer when supplied; the existing surface wind is the fallback. Five-second wind and individual-layer coverage smoothing avoids weather-update jumps. Cloud displacement integrates frame time, including while astronomical time is frozen in a preview. A jump exceeding 30 seconds in the selected UTC instant resets to a deterministic daily phase. Cloud texture repetition and the curved-horizon planar projection remain approximations. Moon sky brightness shares the phase, distance and extinction functions in `atmosphere-light.ts`; rain shading is normalized over 0–8 mm/h.

## Ownership, cost and verification

`createAtmosphereSky` owns one material, one mipmapped 256×256 RGBA noise map and one mipmapped 2048×1024 RGBA catalog map (1024×512 when constructed in low quality). Noise is generated from cached lattice values at construction; no textures are regenerated during updates. The sidereal/precession matrix is refreshed when the selected instant changes by at least one second, bounding the short cache's rotational lag to approximately 15 arcseconds. Clouds use at most three coverage samples, with zero-cover branches, plus **one directional relief sample only when a low cloud is visible and quality is medium or higher**. Celestial discs and low quality keep the three-sample limit and identical masks. Stars use one filtered sample at night. There is no volumetric ray march, per-star draw call or per-frame texture upload. The caller owns the backdrop mesh.

`bindClouds` shares the noise texture and uniforms with celestial materials without transferring ownership. It returns an unbind function. Handle disposal, and scene-triggered disposal, are idempotent. Tests cover true sidereal repeat, east/north axes, an independent precession reference, catalog-to-texture alignment including Polaris, daylight/moonlight star suppression, deterministic seamless noise, and unchanged texture identity through repeated updates. NullEngine is used only for resource lifecycle checks; **it is not GPU or frame-rate evidence**. Production rendering and performance verification belong to `docs/verification.md` after root integration.

The first full-game visual inspection supplied by the integrator showed excessively blurred, sparse low clouds. CPU analysis reproduced the cause: an initial 50% request yielded about 18.3% mean opacity. After calibration, the same request yields 50.002% at atlas texel centres and 49.970% with bilinear subtexel samples. All three channels match tested requests from 10–90% within 0.3 percentage points. The refined star tests check subpixel energy stability and preserved magnitude ordering. These numerical checks explain the correction; subsequent full-game GPU visual acceptance is still required.

## Integrated visual adjustment

Root inspected the new layers in the complete Game on Intel UHD 630 on 2026-10-12. The first CDF variant had overly uniform rounded lobes and bright rims. The final integrated atlas reduces the cellular contribution to 10%, retains 90% FBM with a 0.57 octave falloff, uses a 0.075 rank edge, and reduces relief/silver-edge contrast. These are authored appearance choices; CDF coverage, metric drift and the shared body mask still pass all nine targeted tests. Preliminary screenshots are labelled as such; final production evidence is separate.

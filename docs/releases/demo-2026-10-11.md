# Demo 0.1.0 · první publikovaná verze

Tento dokument popisuje první verzi projektu uloženou do `Varnahg/StrahovCrazyShow`. Jde o vývojové demo pro místní spuštění, nikoliv dokončený fotogrammetrický areál nebo veřejně provozovanou službu.

## Spuštění

Po instalaci Git LFS, Node.js 24 a pnpm 11.25.0:

```powershell
git lfs install
git clone https://github.com/Varnahg/StrahovCrazyShow.git
cd StrahovCrazyShow
git lfs pull
pnpm install --frozen-lockfile
pnpm dev
```

Otevři `http://127.0.0.1:5173/`. API a multiplayer používají místní port 2567; `pnpm dev` spustí obě části. Blender není pro hraní nutný. Podrobný návod, ovládání a test dvou prohlížečů jsou v [README](../../README.md).

## Co tato verze obsahuje

- Jediný společný anonymní svět, synchronizaci postav, přezdívky, gesta a samostatného hosta bez multiplayerových dat.
- Přehled fiktivních akcí, vlastní dočasná setkání, zájmy a účasti, globální/místní/událostní chat a soukromý kontakt po přijetí žádosti.
- Interaktivní mapu a deník, sólové úkoly, společné hledání a týmový kvíz.
- Místní mapu a reliéf Strahova, samostatné budovy, stromy, auta a hřiště, modelový interiér B6 s recepcí a dvěma schodišti.
- Upravitelnou postavu se společnou anatomií a šitými oděvy; novější méně skákavou procedurální chůzi a běh.
- Arkádové ovládání sdíleného auta, ovladatelnou kameru a oddělené modely ambientní dopravy.
- Polohu Slunce/Měsíce podle data, den/noc, označené meteorologické zdroje a plánované PID 143/149 z uloženého feedu 10.–23. 10. 2026.
- Nové zdrojově doložené dopravní značení, prostorové dělení statického terénu a opravu orientace vadných základových ploch.

## Známá omezení

Věrnost všech stromů, fasád, terénních přechodů a interiérů není dokončená. B6 je rekonstrukce podle dostupných podkladů s přiznanými odhady, nikoliv zaměřený aktuální stav. Nové experimenty s očima, vlasy a fotografickou trávou jsou zdokumentované studie; hlavní hra je dosud nepoužívá. Dlouhé vlasy mají ve studii doložené průniky do oděvu. Animace jsou procedurální, nejsou mocap.

Oprava orientace základů neprokazuje odstranění každého uživatelem hlášeného blikání styku trávy a budov. Úplný inventář dopravního značení, přesné polohy sloupků a některé křižovatkové detaily zůstávají otevřené. Historický K4 při 30 avatarech ve dne naměřil na Intel UHD 630 / low / render 1476×830 **31,7–32,5 FPS**, p95 **35,0–40,2 ms**. Cíl 60 FPS tím splněný není; aktuální checkpoint potřebuje vlastní srovnatelné GPU měření.

Žádný IS, ověřené bydliště, skutečné studentské profily, trvalé účty ani zabezpečená veřejná administrace. Dočasná serverová data zmizí při restartu. Osvětlená okna, provoz a cestující jsou simulovaní. Meteorologický model není přesná rekonstrukce skutečných mraků a jízdní řád není živá poloha vozů.

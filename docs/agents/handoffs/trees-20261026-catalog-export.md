## Implementace a refaktoring

Čisté `population.mjs` řeší source-area density, deterministický výběr celých skupin, ranky, parent closure a rigidní fit ke zmrazené bance. `native_geometry.py` vytváří tubes z fitted os se zachováním junctions a near/MID podpěr, metrické listy a původní Fir source mapování. `native_io.py` sjednocuje raw ordered-corner export a přesné porovnání native/GLB. Pipeline `prepare` → `run`/`batch_native` → `build_native`/`fit_far`/`finalize_native` → `verify_runtime`/`publish` je obnovitelný podle autoritativních receipts a nevyžaduje obrovské rozbalené arrays.

Materiálové knihovny sdílejí stejné fotografické mapy jednou za run. `cleanup.mjs` validuje celý bounded delete set před prvním unlinkem; odmítá path escape/symlinky a nerekurzuje. Chrání historické evidence runy. `control.mjs` dává skutečnou bezpečnou pauzu mezi modely. `progress.mjs` počítá shared zdroje jednou a nehashuje při každém progress pollu znovu rostoucí katalog. Všechny modely vznikaly v jediném Blender CPU2 procesu; žádné souběžné GPU scény.

První listnatý pokus odhalil chybu sousedních FNV hashů: azimut se měnil jen o ±1,41° a roll byl spřažený. Numerický counterfactual prokázal příčinu. Chybná evidence zůstala zachovaná; podrobnosti a SHA jsou v `catalog-export.md` a cache reportech.

B5 finální native připojuje nezměněné čtyři near/MID a tři kompletní FAR objekty: 15 947 card +72 exact ranků, celkem 16 019.

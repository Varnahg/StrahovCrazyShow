# Czech and English interface

The client locale is a small external store in `client/i18n.ts`. `getLocale()` reads the current `cs`/`en` value; `setLocale()` publishes a change and saves only `strahov.locale`; `useLocale()` subscribes React with `useSyncExternalStore`. Landing and Settings share the same picker. A language change does not set `mode`, replace the Game instance, change profile data or reconnect the socket. Saved choices take priority over the first supported browser language; unsupported lists fall back to English. The document language and other open tabs follow changes. Storage failure leaves the in-memory choice usable.

`t(key, params)` uses typed Czech source keys and requires named `{parameters}`. `localizeText()` is for known static content only; nicknames, chat and player-authored event fields are never passed through it. `demoEventText()` translates only unchanged built-in event text with a known ID and no owner. `formatNumber`, `formatDate` and `plural` use cached `Intl` formatters/rules. Display dates use Europe/Prague unless an explicit source-date UTC override is provided.

`client/data/journal-en.json` translates all 36 journal articles. This is a translation of the dataset checked on 10 October 2026, not a new fact-check. Tests pin the Czech dataset SHA-256 and article/paragraph/step coverage. Source URLs, author identities, image files, licence links, checked dates, object IDs and factual uncertainty remain in the original dataset. The two cached search indexes allow English topic searches while returning the original entry objects; bookmarks, selected entries and reading progress retain their IDs.

Server messages currently retain the existing string protocol. The client translates a bounded catalogue of known validation errors and notices; unknown technical details remain verbatim. Already displayed notices can switch language too. A future server contract should send `{ code, params, fallbackText }`, with shared code/parameter types and per-client rendering. This change does not translate chat or add locale-dependent server state.

The HUD keeps short icons with accessible names/tooltips, contextual interaction prompts and explicit demo markers. Longer control instructions and simulation explanations are in Help; event details, weather freshness and simulated transport remain labelled where they apply. The map is a centred modal with shared route planning supplied by Game; its dialog focus, Escape, Tab trapping and focus restoration share a small helper with Journal and the event form. Any open panel suppresses gameplay keyboard actions while the world continues.

## Jak aplikace skutečně drží pohromadě

`index.html` → [client/main.tsx](../../client/main.tsx) → `client/ui.tsx` → `client/game.ts`. UI spravuje React stav a Colyseus relaci; Game spravuje Babylon scénu, kameru, fyziku, animace a životní cyklus zdrojů. `client/world-renderer.ts` integruje jednotlivé části světa.

[server/index.ts](../../server/index.ts) spouští HTTP/WebSocket server a právě jednu `StrahovRoom`; stav komunity a relací drží v paměti. Sdílená [shared/simulation.ts](../../shared/simulation.ts) obsluhuje autoritativní fyziku na serveru i klientskou predikci. [shared/netcode.ts](../../shared/netcode.ts) deklaruje protokol **9**, fyziku **60 Hz**, limit catch-up i fronty vstupů. Server odesílá pohybové zprávy **20 Hz**. Změna kolizí může vyžadovat společnou aktualizaci protokolu, i když se struktura paketů nezmění.

`shared/` není odkladiště pomocných funkcí: obsahuje společné prostorové, fyzikální a datové kontrakty. Změna výšky budovy, vstupu či trasy se musí promítnout do vykreslení, kolizí, navigace a případných exportů. Současný hlavní svět používá samostatné autorské modely; historická fotogrammetrie je podle [README](../../README.md) referenční vrstva, nikoli sloučená herní scéna. Samotná existence `photogrammetry-*` souboru není pokyn jej znovu zapojit.

## Co je důkaz a co zůstává otevřené

[docs/verification.md](../verification.md) a [D2 results.json](../verification-evidence/campus-depth-20261012-d2/results.json) dokládají tehdejší snapshot `40f1847ec2d227c7d6eca6ea2bb5d2d5eb1b199a9ea392efe6a8225b71139633`: 573/573 testů, build a izolovaná integrace. D2 produkční vzorek měl jednu syntetickou multiplayerovou relaci, Intel UHD 630, medium, CSS i interně 1280×720, 54,9 FPS, p95 20,2 ms a p99 23,4 ms. Je to konkrétní historický funkční vzorek, nikoli nová GPU přejímka či důkaz výkonu rozpracované atmosféry a venkovních objektů.

Při průzkumu už byly změněné integrační soubory `client/game.ts`, `client/ui.tsx`, `client/world-renderer.ts`, `shared/simulation.ts`, počasí, mapa a jejich testy; zároveň přibyly soubory atmosféry a venkovních objektů. `git status` nedokládá jméno vlastníka. Jejich stav je nutné převzít od současného procesu, nikoli je považovat za volnou práci nebo automaticky začleněné D2. Tento dokument jejich implementaci nemění.

Trvající nároky z [ověření](../verification.md) a [README](../../README.md): jeden společný svět, izolovaný host, pouze dočasné relace, jasně simulované aktivity/NPC, zachovaná provenience, společná fyzika a geometrie, skutečná vizuální kontrola. Neuzavřené zůstávají fotografická věrnost, některé interiéry a povrchy, cílené problémy lokomoce/trávy a přejímka 60 FPS na cílové GeForce s denním multiplayerem. Demo nemá trvalé účty ani distribuovanou simulaci; kapacita jednoho procesu a síťový objem všech vůči všem jsou konečné.

[scripts/performance-snapshot.mjs](../../scripts/performance-snapshot.mjs) kopíruje zdroje, assety **i testy**, klíčovou konfiguraci a stadium fixture `docs/reality-pack/landmarks/geometry-source.json` do `.cache/performance-snapshot/<jméno>`, porovnává SHA před/po kopii a zachovává velké zdrojové balíčky. Zbytek průběžně měněné dokumentace není runtime snapshot. Nová testová datová závislost mimo zahrnuté adresáře vyžaduje vědomou aktualizaci snapshotu.

Při tomto dokumentačním průzkumu byly čteny skutečné soubory, importy, generátory, lockfile a historická evidence; nebyly spouštěny servery, generátory assetů, full suite, build, integrace ani GPU měření. Platnost cest a místních odkazů tohoto dokumentu byla zkontrolována samostatně.

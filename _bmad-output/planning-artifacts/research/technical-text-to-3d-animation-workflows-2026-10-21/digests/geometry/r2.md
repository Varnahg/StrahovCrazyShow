# Geometrie a výtvarné vedení — mezery a aktualizace, druhé kolo

Datum: 2026-10-21 Europe/Prague. Navazuje na [r1.md](r1.md); nové informace zde mají přednost před jeho předběžnými buňkami. Žádné placené generování, přihlášení, instalace, API volání, Blender ani měření neproběhly. Přečteno přes osm dalších primárních zdrojů. Dvě kola ukončena na pokrytí rozhodovacích otázek; další obecné hledání by nenahradilo chybějící pilot.

## Doporučení pro konkrétní rozhodnutí

Navržený pilot má tři cloudové kandidáty, jeden podmíněný lokální a jednu procedurální cestu. Nejde o prokázané pořadí krásy. **Meshy a Tripo porovnat na stejném schváleném concept image**, přidat Rodin pro složité hero objekty, kde chceme vyzkoušet jiné řízení interpretace a topologie. Který poskytne hezčí a opravitelnější výsledek, nebylo změřeno. Pro pohyblivé mechanické díly a opakující se rozměrové konstrukce ponechat explicitní Blender modelování/procedural variantu. Pro rodinu stylizovaných assetů nejprve schválit společnou paletu, tvarový jazyk, proporce a materiály; všechny 3D pokusy hodnotit proti tomuto zadání. Toto jsou návrhy pracovního postupu, ne vlastnosti garantované službou [G05,G08,G18,G22,G28].

## Rozpory s dopadem na rozpočet a integraci

- **Meshy web/Agent/API odlišit.** Aktuální API tabulka je již pro 7.1, image mesh 20 kreditů / s 2K či 4K texturou 30 / 8K 35, Ultra +5; T2/T2.5 mesh 5 / textured 15 [G16]. Web help uvádí Model stage Meshy7 25 + texture 10, zatímco Agent standard mesh20/textured30 [G17]. To vysvětluje část rozdílů prvního kola, nikoli všechny rozpory starší web docs. Nákupní rozpočet má vycházet z vybraného rozhraní a reálného cost preview.
- **Nezačínat novou automatizaci na `lowpoly`.** API hlásí retirement 30. 10. 2026 a doporučuje Smart Topology T2.5 [G18]. `latest` je nyní 7.1 a není vhodné ho vydávat za stabilní identitu pokusu; uložit konkrétní model a parametry.
- **Text-to-3D není vždy jedna atomická operace.** Meshy API je preview mesh + refine texture [G19]. Rodin Gen-2.5 text interně nejprve renderuje do obrázku [G23]. Výběr vlastního concept image je proto samostatný kontrolní bod výtvarného směru, ne záruka, že je technicky jedinou cestou k obrázkovému mezikroku.
- **Tiskové dělení není díl pro animaci.** Meshy Auto Split po změně ze 16. 9. přijímá i texturovaný vstup, ale vrací přestavěné netexturované díly s plochou barvou [G20]. Tripo má skutečný segmentation endpoint [G21]; správné názvy, mechanické pivoty, vnitřní povrchy a anatomický význam dílů v reálném exportu nejsou tímto doloženy.

## Předání do Blenderu a k animaci

Doložené cloudové exporty jsou síťové formáty [G04,G09,G23]; z těchto seznamů nelze tvrdit přímou tvorbu nativního `.blend` s parametry, modifikátory a historií. Praktická navržená cesta je import GLB pro PBR kontrolu nebo FBX při požadavku na quad strukturu/rig, následně uložit nativní Blender master. TRELLIS.2 ukázka také exportuje GLB [G25]. Samotný úspěch exportu se zde netestoval.

Navržené přejímací body (neprovedené testy):

1. U jedné stylizované postavy, organického netvora a mechanického rekvizitního objektu schválit concept sheet a zamýšlené pohyblivé části. Nepoužívat jméno existující IP jako náhradu vlastního designu.
2. Každou generaci otočit o360°, zobrazit bez textur, hledat přilepené dekorace, chybné otvory, chybějící zadní detaily, tenké výčnělky a náhodné asymetrie. Jde o návrh auditu, nikoli zjištění konkrétního chybného modelu.
3. Ověřit síť, materiálové sloty, UV/švy, texel density a packed maps po skutečném importu. Pro změnu topologie používat pořadí remesh → UV → retexture, které doporučují i Meshy docs [G32,G33]. Neztratit detailní originál.
4. Před rigem zkusit loket/koleno/rameno nebo vlastní mechanismus; neměnit topologii poté bez retestování vah/UV. Předat motion výzkumníkovi skutečnou kostru, jména a oddělené díly, ne pouze prompt nebo beauty render.
5. V exportním runtime ověřit jednotky, orientaci, pivoty, počet trojúhelníků, počet materiálů, transparentní plochy a velikost textur. Herní výkon a vizuální kvalita v cílové scéně zůstávají otevřené.

## Dosavadní závěr

Pro přesně zadané pohyby mechanických/pevných dílů dává smysl pilot **text → LLM → Blender Python → pojmenované objekty / klíče → `.blend` + GLB**. Jde o návrh založený na dostupném API, nikoli o prokázanou obrazovou kvalitu. MCP přidává zpětnou vazbu ze scény; samo není naučený generátor geometrie ani pohybu. U organických tvorů zůstávají kvalita modelu, váhy a přenos pohybu samostatné úlohy. [S1](https://github.com/ahujasid/mcp-for-blender), [S6](https://docs.blender.org/api/5.2/bpy.types.bpy_struct.html)

Je nutné oddělit autorovací soubor a runtime: `.blend` lze skutečně uložit; importované GLB/FBX tím automaticky nezíská původní konstrukční historii. Exportní profil se musí testovat na konkrétní stabilní verzi. Úspěšné přehrávání v Blenderu není důkazem stejného výsledku v GLB. [S5](https://docs.blender.org/manual/en/5.2/addons/scene_gltf2.html), [S7](https://docs.blender.org/api/5.2/bpy.ops.wm.html)

## Malý doložený API základ (ilustrace, NE spuštěný pilot)

Předpoklad: `obj` již je vlastní vybraný objekt. Klíče lze ručně editovat; zachování ostatních klipů musí zajistit strategie Action/slotů, nikoli pouhé opakování skriptu. [S6](https://docs.blender.org/api/5.2/bpy.types.bpy_struct.html)

```python
obj.location = (0, 0, 0)
obj.keyframe_insert(data_path="location", frame=1)
obj.location = (0, 0, 2)
obj.keyframe_insert(data_path="location", frame=25)
```

Skutečný autorovací checkpoint vytváří například následující volání. Cesta je ilustrativní; v tomto běhu nevznikl `.blend`. [S7](https://docs.blender.org/api/5.2/bpy.ops.wm.html)

```python
bpy.ops.wm.save_as_mainfile(filepath="/absolute/pilot/source.blend")
```

## Konkrétní limity a další kolo

- README nabízí safe mode, ale ten není default; socket podle README nemá autentizaci/šifrování. Do dalšího kola patří čtení implementace validace, nikoli převzetí slibu o sandboxu. Bezpečný režim nadále dovoluje Blender save/import/export. [S1](https://github.com/ahujasid/mcp-for-blender)
- Obsah může proudit z lokálního Blenderu do zvoleného LLM; privacy tohoto LLM není předmětem zde čtených podmínek. Čistě lokální Python workflow MCP ani generátor API nepotřebuje (inference z architektury S1/S2). Přesné tokenové ceny LLM ani Premium generování nebyly ověřeny.
- Chybí nezávislý primární doklad glTF kontraktu, správná nízkoúrovňová práce s novými Actions/sloty, shape-key topologie a Geometry Nodes lifecycle. Kolo 2 řeší tyto konkrétní mezery. Neplánuje další produktový katalog.
- Bez pilotu není prokázaná estetika, bezchybná textová iterace, Blender 4/5 matice ani runtime rozpočet. Galerie a uvedené minimum 3.0 takové důkazy nenahrazují.

Přímé citace v artefaktu: žádné dlouhé výňatky; zdroje jsou parafrázované. Osm zdrojů poskytuje technický podklad, ne úspěšný end-to-end export.

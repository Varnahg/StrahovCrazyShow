# Doplňující externí primární podklady — lead

Accessed u všech2026-10-20. Primární zdroje jsou veřejně čtené, žádný testovací report nebyl odeslán.

- Charles Cordingley, **Concealed Intent: In-game Feedback Forms**,2015-03-26, https://www.gamedeveloper.com/programming/in-game-feedback-forms . Autor vlastní implementace popisuje krátký herní formulář, dostupný shortcut a automatické přiložení existujícího herního logu. Screenshot a framerate uvádí jako možné další doplnění, nikoli jako již dodané vlastnosti. Jde o historickou zkušenost jednoho vývojáře, ne experimentální důkaz konverzního přínosu. Dva textové vstupy a částečné předvyplnění, většina obsahu optional. Primary-confirmed; střední jistota.
- Dream Harvest / Justin French, programátor Sven, **Failure: In game Bug and Feedback system for Unity**,2015-05-04, https://www.gamedeveloper.com/business/in-game-bug-and-feedback-system-for-unity . Přímý formulář posílal do JIRA; příchozí reporty oddělené od interního vývojového backlogu; po ověření slučovali duplicity a teprve pak přesouvali. Screenshoty v době článku výslovně teprve plánovali. Zlepšení množství/kvality reportů je autorova krátkodobá anekdota bez čísel a kontrolní skupiny.
- Unknown Worlds, **snfeedback**, https://github.com/unknownworlds/snfeedback , historický GDC2015 vzor, přesný commit neověřen. README potvrzuje herní frontend, sběrný backend a webovou prezentaci a výslovně odmítá turnkey funkční kopii. Současná produkční implementace a parametry tím nejsou doloženy.
- Owlcat Games, **Beta Bug Report instructions (WIP)**, https://owlcat.games/instruction , datum unknown; obsah sám označuje beta Pathfinder Wrath of the Righteous. Text PDF potvrzuje Alt+B, kontext hover objektu/NPC, aspekt a popis/repro, privacy a crash fallback s logs/save/dmp. Aktuální support https://owlcat.games/support/1000 potvrzuje Alt+B a webový fallback. Z otevřeného textu PDF nelze doložit automatické screenshoty ani HUD-free. Screenshot PDFp2 přes web nástroj načten jako reference, p3 timeout; žádná vizuální vlastnost nebyla z nezobrazených pixelů odvozena.
- Mozilla MDN, **Storage quotas and eviction criteria**, https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria , datum publikace unknown. IndexedDB je vhodné pro strukturovaný draft/Blob, ale storage je default best-effort, kvóty a eviction se liší, InPrivate obvykle data po skončení odstraní. Z toho neplyne zaručené doručení po zavření prohlížeče.
- Mozilla MDN, **Navigator.sendBeacon()**, https://developer.mozilla.org/en-US/docs/Web/API/Navigator/sendBeacon , datum publikace unknown. Návrat true znamená zařazení transportu, ne server receipt; queued data limit64KiB. Proto screenshot nelze opřít o odchodový beacon a potvrzení must vycházet z odpovědi serveru.
- W3C WAI, **Dialog (Modal) Pattern**, https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/ , datum publikace unknown. Focus při otevření dovnitř, Tab/ShiftTab uvnitř a Escape zavírá. Jde o behaviorální podklad budoucího formuláře, nikoli důkaz současného UI hry.

Nezávislost: Concealed Intent a Failure jsou různí autoři/vývojáři se zkušeností v jejich vlastních hrách. Shoda ve využití krátkého herního formuláře podporuje jeho proveditelnost a rozumnost, nikoli číselně optimální počet polí nebo konverzi. Subnautica guide/studio/backend/repo jsou stále jeden publisher.
